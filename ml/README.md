# ConfigVista AI - Machine Learning Module

## Intelligent Network Change Risk Prediction

**Version:** 3.0 (Phase 3)

**Author:** Shivam Saxena

---

# Overview

The Machine Learning (ML) module extends ConfigVista AI by introducing data-driven risk prediction for Cisco IOS configuration changes.

While Artifact-1 provides a deterministic rule-based risk assessment engine, this module investigates whether supervised Machine Learning models can improve the accuracy and consistency of operational risk prediction.

The ML pipeline transforms structured configuration comparison results into numerical features, trains predictive models, evaluates their performance, and provides explainable predictions for network engineers.

---

# Objectives

The Machine Learning module has the following objectives:

- Generate structured datasets from configuration comparison results
- Extract meaningful engineering features
- Prepare datasets for supervised learning
- Train Machine Learning models
- Compare multiple algorithms
- Explain model predictions
- Integrate ML predictions into the Streamlit dashboard

- Added Line Count

- Child Command Count
- Configuration Complexity
- Total Changes

## Boolean Features

- Routing Change
- Interface Change
- Security Change
- Switching Change
- Services Change
- Management Change
- System Change

---

The prediction target is the operational risk label.

Possible values:

- Low
- Medium
- High

# Summary

The Machine Learning module forms the research contribution of the ConfigVista AI dissertation.

It builds upon the completed rule-based comparison engine by introducing supervised Machine Learning models capable of learning from historical configuration changes and predicting operational risk with improved accuracy.

The modular architecture enables experimentation with multiple algorithms while maintaining transparency, scalability, and future extensibility.
